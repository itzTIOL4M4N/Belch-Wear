# Belch-Wear 🛍️

**Uma experiência de moda urbana que conecta estilo, atitude e tecnologia.**

## 📌 Sobre o projeto

O **Belch-Wear** é um projeto de desenvolvimento de uma loja virtual voltada para o segmento de brechó e streetwear, com identidade visual inspirada na cultura urbana e no hip-hop.

A proposta é oferecer uma plataforma onde os usuários possam conhecer produtos, criar uma conta e realizar suas compras por meio de uma experiência simples, intuitiva e responsiva.

O projeto busca unir tecnologia, comércio eletrônico e identidade visual, utilizando uma interface moderna com predominância das cores preto e branco e elementos inspirados na estética do graffiti.

## 🎯 Objetivo

Desenvolver uma loja virtual que permita a exposição e comercialização de peças de moda urbana, proporcionando uma experiência de navegação acessível tanto em computadores quanto em dispositivos móveis.

## ⚙️ Funcionalidades previstas

- **Catálogo de produtos:** exposição de peças de brechó e streetwear.
- **Cadastro de usuários:** criação de contas para os clientes.
- **Login:** autenticação e acesso à conta do usuário.
- **Carrinho de compras:** seleção e organização dos produtos escolhidos.
- **Pagamento:** integração de um sistema para processamento de compras.
- **Design responsivo:** adaptação da interface para diferentes tamanhos de tela.
- **Banco de dados:** armazenamento das informações necessárias para o funcionamento da plataforma.

## 🎨 Identidade visual

A identidade visual do Belch-Wear é inspirada na cultura streetwear e no hip-hop.

Principais características:
- Paleta de cores em preto e branco.
- Elementos visuais inspirados no graffiti.
- Estética urbana e moderna.
- Interface objetiva e intuitiva.
